# 💪 Daily Protein & Calories Calculator

A simple and aesthetic web-based calculator that estimates your **daily protein intake** and **calorie needs** based on your **gender, age, weight, and height**.

---

## 🚀 Features

- 🎯 Calculates daily **protein requirement**
- 🔥 Estimates daily **calorie intake (BMR-based)**
- ✅ Input validation for accurate results
- 🎨 Modern UI with glassmorphism design
- 📱 Responsive layout (works on mobile & desktop)

---


 ## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling (Glass UI)  
- **JavaScript (Vanilla JS)** – Logic & calculations
